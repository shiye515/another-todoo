## Context

App 的"发送到设备"按钮目前调用简化版 `TodooCardTransferService`，无任何进度反馈 UI；且相比仓库内参考实现 `raw/TodooCard_Skills-main/todoocard-skills/scripts/mac_image_transfer.swift`（1276 行 CLI 协议工具），缺少广播安全校验、安全链路验证、校验窗口可靠传输、控制命令超时回退、失败诊断等机制。本次用原生 Swift 重写发送功能（完整移植参考协议状态机，仅 raw 传输路径，兼容全部固件），并新增发送进度弹窗。

## 变更内容

### 1. 重写 `macos/Services/TodooCardTransferService.swift`

保留 `@MainActor ObservableObject` 形态与现有集成点（`DetailPlaceholderView` 中实例化），以参考实现为蓝本移植协议状态机（payload 始终 raw、握手 flags 0x03）：

- **广播解析与安全闸门**：`AdvertisementInfo`（manufacturerID/screenType/capabilityFlags/firmwareVersion 及派生属性）；身份校验 0x5053/0x134C；配对窗口开启→拒绝传输；OTA 恢复模式→拒绝
- **连接管理**：最多 3 次连接尝试、每次 15s 超时；加密超时（CBErrorDomain code 15）自动重试
- **安全链路验证**：加密 Battery (180F/2A19) 读取验证系统配对；成功后等待 1.8s Service Changed 缓存刷新并重新发现服务
- **GATT 发现**：图片服务 FEF0/FDF0、控制 FEF1/FDF1（setNotify + 400ms settle）、数据 FEF2/FDF2；3s/8s 服务发现重试；35s 准备超时
- **握手序列**：requestBlockSize(0x01) → requestScreenSize(0x02, LE 长度 + flags 0x03) → requestStartTransfer(0x03)
- **数据传输双策略**：
  - 固件 ≥ 0x9D：32 块校验窗口 + durable checkpoint（0x05 ACK 带索引）、窗口尾块 repair probe（最多 16 次）、窗口末 barrier withResponse 写
  - 旧固件：逐块 ACK 驱动顺序传输
- **控制命令容错**：withResponse 写 + 600ms 无响应回退 withoutResponse 重试
- **成功判据**：必须收到 0x05/0x08 刷新确认（校验窗口 10s / 标准路径 5s 等待）；断连不视为成功
- **错误映射**：0x01 块格式/顺序错、0x09 Flash 写失败、0x0A Flash 回读校验失败
- **失败诊断**：固件 ≥ 0xA5 时读诊断特征 `D8B282F0-0F9B-4A7A-B5E8-8E6E5A3C1003`（服务 `...1001`），解析 ImageAckDiagnostics 并保留文本
- **对 UI 暴露的状态**：`phase` 枚举（idle/scanning/connecting/verifying/negotiating/transferring/waitingRefresh/succeeded/failed/cancelled）、`progress`（0...1）、`statusText`、`bytesSent/bytesTotal`、`lastError`、`diagnosticsText`；`startTransfer(controllerPayload:deviceID:)`、`cancel()`；扫描 45s 总超时

### 2. 新建 `macos/Views/TransferProgressSheet.swift`

发送进度弹窗（以 sheet 呈现）：
- 设备名、阶段文案、线性 `ProgressView` + 百分比 + 已传/总字节
- 传输中提供"取消"按钮
- 成功：✓ 提示，约 1.5s 后自动关闭
- 失败/取消：红色错误信息（附带诊断文本，若有）+ "关闭"按钮
- `onAppear` 时触发 `startTransfer`

### 3. 修改 `macos/Views/ImageView.swift`

- `sendPreview` 改为：校验图片与默认设备 UUID → 暂存待发 payload/deviceID → 打开进度弹窗（不再直接调用 transfer）；UUID 无效时写入 `processor.errorMessage`
- 现有按钮禁用逻辑（无图片/无默认设备）保留
