设计说明（实现映射）
  • 布局：图片页 = 库列表（左，218pt）+ 详情区（右）。库列表负责资产管理；详情区完整展示原图与全部量化预览。
  • 量化算法可扩展：详情区的变体卡片由数据驱动（ALGORITHMS 数组），新增算法 = 数组追加一项 + 一个量化函数，卡片自动出现在横向滚动行末尾，布局不破。
  • 发送模型：此前每算法一个发送按钮，改为「点击卡片选中 + 底部统一发送」——按钮数量不随算法增多而膨胀；选中状态随条目记忆。
  • 重新量化：每张变体卡右下角提供「重新生成」，从成品图重算该量化图并覆盖持久化副本。
  • 原图说明：界面标注的「原图」为 528×792 裁剪成品（原图不保留），卡片副标题已注明尺寸。
  • SwiftUI 映射：变体行 = LazyHStack（或 ScrollView(.horizontal)）+ 卡片视图；选中 = entry.selectedVariantID；发送 = pendingTransfer sheet。
